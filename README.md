No teste automatizado deste reposotório utilizando o site de reservas (para testes) Restful-booker-plataform, criei cenários de fluxos positivos e negativos que serão testados afim de validar o comportamento da UI 
onde o usuário final irá inserir dados e realizar ações de click, select, filter e afins.

Boas práticas:
• Projeto inteiramente utilizado com Page Object Model (POM), visando a manutenção durante sua vida útil. ✅
• Implementação de interfaces e dados apartados em .json, afim de melhorar a inserção dos dados e facilitar no manuseio. ✅
• Seletores robustos, onde mudanças no site não impactam na estrutura do código. ✅
